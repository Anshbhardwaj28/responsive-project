# Responsive Frontend Interface

A responsive landing page built with HTML, CSS, and JavaScript that adapts to mobile, tablet, and desktop screens.

**Live Demo:** https://Anshbhardwaj28.github.io/responsive-project/

## Features

- Mobile-first, responsive layout (CSS Grid + Flexbox)
- Sticky navigation bar with a hamburger menu on mobile
- Hero section, feature cards, and contact form
- Basic JavaScript form handling and menu toggle
- Clean, user-friendly UI with no external libraries

## Tech Stack

- HTML5
- CSS3 (media queries, Grid, Flexbox)
- JavaScript (ES6)
